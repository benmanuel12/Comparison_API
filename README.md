# Comparison_API

Frontend and backend for 3rd year university project to create a price comparison website with webscrapers
Web scraper code located at https://github.com/benmanuel12/WebScrapers
The website scrapes trading card websites for the prices of Magic: The Gathering cards then uploads the data to a database and allows the user to search and view the database through the page

## Built with
Node.js, Spring, Hibernate, Java, Axios, SQL, Mocha/Chai

## Features
- Allows CRUD actions on the database of cards
- Has search functionality
- Also has links to the original source of card prices so people can go and buy the cards

## Running it
- Install dependencies and run the node server

Disclaimer: This project may no longer work due to the scrapers being incompatible with the website if the pages have changed. This code is not affected but is much less useful without the correct format of data.
